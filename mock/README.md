# SupplyGuard — 프론트엔드 목업

정적 HTML · 바닐라 JS · 외부 라이브러리 없음. React 대시보드(`frontend/`)와 **같은 화면 5개·같은 데이터 스키마·같은 디자인 토큰**을
쓰되, 백엔드 없이 브라우저만으로 열린다. 처음 보는 사람이 화면만 보고 "관찰 → 판정 → 격리 → 정책 → 감사" 흐름을 따라갈 수 있는지
검토하는 용도다.

## 열기

- `mock/index.html` 을 브라우저로 바로 연다 (file:// 로 동작)
- 또는 `cd mock && python3 -m http.server 8765` → http://127.0.0.1:8765/
- 키보드 `?` 또는 상단 **? 안내** → 5단계 사용 안내. 상단 **데모 제어** → 공격 시나리오 즉시 실행·격리 모드(dry-run) 전환·연결 끊김 재현

## 무엇이 움직이나

| 기능 | 어디서 |
| --- | --- |
| 실시간 스트림 시뮬레이션 | 백엔드 mock 소스와 같은 컨테이너 3개(`web-api`·`worker`·`pkg-reqeusts`)가 100ms 마다 정상 이벤트를 내고, 20초마다 타이포스쿼팅 컨테이너가 시나리오 1→2→3(`curl\|sh` → `/etc/shadow` → `203.0.113.7:4444`)을 일으킨다. 250ms 배치 렌더, 최근 500건 유지, 일시정지 |
| 규칙 평가 | `shared/data.js` 의 `evaluate()` 가 `backend/policies/default.yaml` 5개 규칙을 백엔드 엔진과 같은 순서(allow 먼저 · 가장 강한 대응 우선)로 평가한다. 정책 화면에서 고치면 다음 이벤트부터 반영 |
| 격리 | kill 판정 + 격리 모드면 컨테이너가 **격리됨**으로 표시되고 토스트·격리 KPI·상단 종 배지가 뜬다. 15초 뒤 새 ID 로 재기동(재배포 흉내). dry-run 이면 **격리 대상**(점선) |
| 대시보드 | KPI 4개 · 가상 스크롤 피드 · 5분 추이 SVG 라인 차트(hover 값) · 위반 Top 컨테이너(클릭 → 토폴로지 필터) |
| 이벤트 | Kind·판정·컨테이너 필터 + 실시간/1h/24h(감사 로그) · 행 클릭 → 상세 패널(원본 JSON·관련 정책 링크). 종 아이콘 → `#/events?verdict=violation` |
| 토폴로지 | 컨테이너 → 프로세스 → 파일/목적지 3열 고정 레이아웃 SVG. 위험 노드·엣지는 붉게(점선 애니메이션), 1/5/15분 창, 컨테이너 필터 |
| 정책 | 목록 · 폼 ↔ YAML 편집(자체 최소 파서) · dry-run 스위치 · 두 번 눌러 확정하는 삭제 · 전체 YAML 교체 · 관리자 토큰 입력(목업은 아무 값) |
| 감사 로그 | 시드 고정 위반 이력 약 900건(24시간) · Kind/대응/규칙/컨테이너/기간 필터(300ms 디바운스) · 100건씩 더 보기 |

## 구조

| 파일 | 역할 |
| --- | --- |
| `index.html` | 진입점 — 스크립트 3개를 순서대로 읽는다 |
| `shared/data.js` | 컨테이너·공격 시나리오·기본 정책·규칙 평가·시드 고정 감사 로그 (`window.MOCK`) |
| `shared/app.js` | 셸(사이드바·상단바·흐름 레일·종 배지) · 해시 라우터 · 공통 컴포넌트(배지·KPI·패널·가상 스크롤 피드·라인 차트·토폴로지 SVG·토스트·확정 버튼·스위치) · 실시간 시뮬레이션(소스+파이프라인+통계) · 안내 대화상자 · 데모 제어 드로어 (`window.UI`) |
| `shared/screens.js` | 화면 5개 (`UI.screens['/']` … `['/audit']`) — `frontend/src/features/*` 와 1:1 |
| `shared/styles.css` | Tailwind slate/indigo 토큰을 CSS 변수로 옮긴 스타일. 페이지 고정·본문만 스크롤 |

## 렌더 확인

`python3 -m http.server 8765` 로 띄운 뒤 Playwright(1440×900)로 5화면 + 상호작용(행 선택·필터·YAML 전환·저장·전체 교체·감사 필터·데모 공격·안내·일시정지)을 돌려
콘솔 오류·경고 0건을 확인했다 (2026-09-29). 같은 스크립트로 nginx 뒤의 실제 컨테이너 대시보드도 찍어 화면이 일치하는지 나란히 비교했다.
