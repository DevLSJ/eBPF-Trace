# SupplyGuard — 프론트엔드 목업

정적 HTML · 바닐라 JS · 외부 라이브러리 없음. React 대시보드(`frontend/`)와 **같은 화면 5개·같은 데이터 스키마·같은 디자인 토큰**을
쓴다. 처음 보는 사람이 화면만 보고 "관찰 → 판정 → 격리 → 정책 → 감사" 흐름을 따라갈 수 있는지 검토하고, 실제 화면(React)에
반영할 UI/UX 를 먼저 그려 보는 용도다. 토폴로지 재설계처럼 목업에서 확정한 것은 React 에 이식한다.

## 열기

| 방법 | 명령 |
| --- | --- |
| 파일로 바로 | `mock/index.html` 을 브라우저로 연다 (file:// 로 동작) |
| 로컬 서버 | `make mock` → http://127.0.0.1:8766/ (8765 는 다른 프로젝트 목업이 쓰므로 8766) |
| 실제 백엔드에 붙여서 | `make backend` (또는 `make dev`) 로 mock 소스 백엔드를 :8000 에 띄운 뒤 데모 제어 → **데이터 소스: 실제 백엔드 → 연결**. 또는 URL 에 `?source=live&api=http://127.0.0.1:8000` |

키보드 `?` 또는 상단 **? 안내** → 5단계 사용 안내. 상단 **데모 제어** → 데이터 소스 전환 · 공격 시나리오 즉시 실행 · 격리 모드(dry-run) 전환 · 연결 끊김 재현 · 이벤트 속도.

## 데이터 소스 두 가지

| 소스 | 피드·통계 | 정책 | 감사 로그 | 데모 제어 |
| --- | --- | --- | --- | --- |
| **내장 시뮬레이션** (기본) | 백엔드 mock 소스와 같은 컨테이너 3개(`web-api`·`worker`·`pkg-reqeusts`)가 100ms 마다 정상 이벤트를 내고, 20초마다 시나리오 1→2→3 을 일으킨다. `shared/data.js` 의 `evaluate()` 가 기본 정책 5개를 백엔드 엔진과 같은 순서로 평가 | 메모리 | 시드 고정 약 900건(24h) | 전부 동작. **지금 실행**은 격리 중이던 컨테이너를 먼저 재기동하고 일시정지도 해제한 뒤 바로 흘린다 |
| **실제 백엔드** | `GET /api/events/recent`·`/api/stats` 로 채우고 `/ws/events` 로 실시간 수신 (1s→10s 백오프 재연결) | `GET/POST/PUT/DELETE /api/policies` (Bearer 토큰) | `GET /api/audit` (id 커서) | 격리 모드·공격 실행은 백엔드 설정을 따르므로 안내만 뜬다 |

실제 모드는 다른 출처에서 REST 를 부르므로 백엔드 `ALLOWED_ORIGINS` 에 이 페이지의 출처(`http://127.0.0.1:8766`, 파일로 열었으면 `null`)가 있어야 한다.
`make backend` 가 그렇게 띄운다. 연결이 안 되면 상단에 붉은 배너로 이유가 나온다.

### 토폴로지 설계 (2일차 재설계 — React 에도 이식)

컨테이너 → 프로세스 → 파일/목적지 3열 고정 레이아웃. 위험한 것이 위로 오도록 정렬한다.

- **엣지 위에 글자를 두지 않는다.** 예전엔 `open`/`connect` 라벨이 곡선·화살표와 겹쳤다. 종류는 말단 노드 안의 **kind 칩**(`open` 하늘색 · `connect` 청록)으로, 횟수는 노드 오른쪽 **×N** 으로 보인다.
- 컨테이너 노드 오른쪽에 **상태 칩**(격리됨·격리 대상·경고). 격리 대상은 점선 테두리.
- 위반 엣지는 굵고(2.25px) 점선이 흐른다. 노드에 마우스를 올리면 그 노드의 연결선만 남고 나머지는 흐려진다.
- 노드를 누르면 오른쪽에 **선택한 노드** 카드: 종류·이름·컨테이너·판정·횟수/위반·마지막 시각·걸린 규칙(정책 화면 링크)·사유·"이벤트에서 보기".
- 오른쪽 **공격 체인** 패널: 컨테이너별로 위반을 일으킨 노드를 데모 시나리오 순서로 나열한다 — **1 실행**(프로세스의 exec 위반) → **2 파일**(open) → **3 통신**(connect). 각 단계에 규칙 id 와 판정 배지. 누르면 그래프의 해당 노드와 연결선이 강조된다.
- 긴 경로는 가운데 말줄임(`/usr/loc…usts/__init__.py`), 전체는 툴팁.

## 구조

| 파일 | 역할 |
| --- | --- |
| `index.html` | 진입점 — 스크립트 3개를 순서대로 읽는다 |
| `shared/data.js` | 컨테이너·공격 시나리오·기본 정책·규칙 평가·시드 고정 감사 로그 (`window.MOCK`) |
| `shared/app.js` | 셸 · 해시 라우터 · 공통 컴포넌트(배지·KPI·패널·가상 스크롤 피드·라인 차트·토폴로지 SVG·토스트·확정 버튼·스위치) · 시뮬레이션(소스+파이프라인+통계) · 실제 백엔드 클라이언트(REST+WS) · 화면용 데이터 API(`UI.api`) · 안내 · 데모 제어 (`window.UI`) |
| `shared/screens.js` | 화면 5개 (`UI.screens['/']` … `['/audit']`) — `frontend/src/features/*` 와 1:1 |
| `shared/styles.css` | Tailwind slate/indigo 토큰을 CSS 변수로 옮긴 스타일. 페이지 고정·본문만 스크롤 |
