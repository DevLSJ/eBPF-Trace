# pay-analytics-demo

**보안 탐지 시연용 무해 패키지입니다.** 실제 npm 레지스트리에 배포하지 않습니다 (docs/13 §8, ADR-019).

공급망 공격 탐지 시스템의 런타임 축을 시연하기 위해, 오염된 의존성이 하는 전형적 행동
(설치/사용 시 외부 서버로 비콘 전송)을 **무해하게** 흉내 냅니다.

- `track(kind)` 호출 시 자식 프로세스 체인 `sh -c → curl`로 **모사 외부 서버 `fake-c2`**(compose 내부)에 접속합니다.
- 보내는 내용은 고정 문자열(`?e=<kind>`)이며, 실제 비밀값·환경변수는 전송하지 않습니다.
- 접속 대상은 `PAY_ANALYTICS_ENDPOINT`(기본 `http://fake-c2:9001/beacon`)로, compose 네트워크 밖으로 나가지 않습니다.
