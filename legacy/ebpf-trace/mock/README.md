# eBPF Trace — 프론트엔드 목업 (3 버전)

정적 HTML · 바닐라 JS · 외부 라이브러리 없음. 세 버전이 **같은 화면·데이터·기능**을 공유하고 셸(사이드바·상단바)과 디자인 토큰만 다릅니다.
2026-09-28 React 프론트엔드 리뉴얼과 같은 구조라, 처음 사용자가 화면만 보고 흐름을 따라갈 수 있는지 세 버전으로 나란히 비교할 수 있습니다.
Loguard 어드민 목업(`~/Documents/Loguard/mockup`)에서는 **기능 트릭**(페이지 고정·본문만 스크롤·휠 관성·토스트·사이드바 접기·배지)만 가져왔고 디자인은 Trace 것을 씁니다.

## 열기

- `mock/index.html`을 브라우저로 열면 버전 선택 → v1 / v2-A / v2-B
- 로컬 서버: `cd mock && python3 -m http.server 8765` → http://127.0.0.1:8765/
- 화면 아래 가운데 전환 칩으로 **같은 화면**을 다른 버전으로 봅니다 (URL 해시 유지)

## 리뉴얼로 들어간 것 (세 버전 공통)

| 기능 | 어디서 보나 |
|---|---|
| 페이지 고정 · 본문만 스크롤 | 어느 화면이든 사이드바·상단바는 제자리, `.page-body`만 스크롤(휠 관성, 표는 `.grid-scroll` 안에서만) |
| 대시보드 한 화면 고정 | `/overview`는 데스크톱(≥1024×900)에서 본문도 스크롤되지 않는다. 위쪽 블록을 압축하고 탐지 이벤트 표(`fill`)만 남은 높이를 채워 행만 스크롤. 낮은 창은 본문 스크롤로 복귀 |
| 사용 흐름 레일 | 상단바 가운데 **1 관찰 › 2 체험 › 3 검토 › 4 대응 › 5 분석**. 현재 화면이 강조되고 누르면 이동 |
| 사용 안내 | 상단바 물음표 또는 <kbd>?</kbd> 키 → 5단계 안내 대화상자(각 단계에서 화면으로 이동) |
| 알림 센터 | 상단바 종 아이콘 + 읽지 않은 수 배지 → 오른쪽 드로어(전체/탐지/시스템 필터, 모두 읽음, 기록 열기). 드로어 아래 **데모: 새 탐지** 버튼으로 배지 튐·토스트를 재현 |
| 토스트 · 스낵바 | 오른쪽 아래 토스트(연결·시나리오·새 탐지, 행동 버튼 1개) / 화면 위 가운데 스낵바(사건 대응 행동 결과, 8초 뒤 소멸) |
| 사이드바 | 사용자 여정 순 4그룹(모니터링 · 위협 대응 · 실습·분석 · 설정) + 캡션, 접기/펼치기(기억), '탐지 이벤트' 미확인 배지, '대응 관리' 승인 대기 배지, ≤768px에서는 메뉴 버튼으로 여는 서랍 |
| 상태 신호등 · 온보딩 | 대시보드·시스템 상태 상단의 정상/주의/문제 배너, 처음 방문 카드(닫으면 기억) |
| 스켈레톤 · 화면 전환 | `ui.skeleton()`, 화면 종류가 바뀔 때 `.page-enter` 페이드 |
| 탐지 이벤트 상세 | 사람이 읽는 한 문장 요약 + 접힌 관측 항목 + 분석가 검토 폼(대시보드·탐지 이벤트·알림 드로어에서 공유) |
| 사건 상세 | 진행 단계 스테퍼(도달 단계 파란 원·진행 중 링), '다음 할 일' 카드의 상태별 안내 문장, 차단 안전 점검(Gate)의 "왜 승인이 필요한지" 문장 |
| 실시간 검사 | `/live` — 토큰 입력 → 와이파이·유선 랜 카드 선택 → 검사 시작(목업은 15초 카운터 검사를 시뮬레이션: 7~9초 트래픽 급증 → 탐지 3건·사건 1건 → 탐지 기록·알림 센터·토스트로 연결) → **방어선 점검** 버튼이 수집·1차 규칙·2차 AI·대응 네 줄의 판정표를 펼침 |

## 화면 (15 + 로그인)

모니터링: 네트워크 대시보드 `/overview` · **실시간 검사 `/live`** (관리자 토큰 → 인터페이스 선택 → 수집 › 1차 규칙 › 2차 AI › 대응 4단계 · 방어선 점검) · 탐지 이벤트 `/events` · 시스템 상태 `/system`
위협 대응: 대응 관제 `/operations` · 사건 받은편지함 `/incidents` · 사건 상세 `/incidents/detail?id=` (개요 · 증거 · **대응(게이트)** · 타임라인) · 대응 관리 `/actions` · 알림 센터(전달 기록) `/notifications`
실습·분석: 탐지 시나리오 `/scenarios` (실행 기록 상세 · 단계 스테퍼) · 데이터 분석 `/analysis`
설정: 탐지 설정 `/settings` · 자산과 대응 지점 `/assets` · 모델 운영 `/models`
