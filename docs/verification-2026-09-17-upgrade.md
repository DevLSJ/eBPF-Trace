## 구현 범위

- 패킷 증거로 CSV 정답 시각 복원, 보수적 정답 결합 및 SHA-256 검증.
- 6개/9개 피처를 같은 복원 표본·시간 분리로 비교하는 오프라인 평가.
- 4개 모의 탐지 시나리오, 관리자 실행·중지, 요청 중복 방지, 실행 임계값 보존.
- 실제 탐지 엔진 공유, 이벤트·샘플 원자적 저장, 저장 후 WebSocket 전송.
- 독립된 DB 탐지 이벤트 페이지, 심각도/유형/출처/검토/IP/기간/실행 ID 검색, DB 집계 그래프.
- 정탐·오탐 판정 및 메모 저장, 이벤트 상세 ↔ 시나리오 실행 그래프 이동.
- 기존 이벤트를 `live`로 보존하는 Alembic 마이그레이션 `89c6d1e42a10`.

실행 시나리오는 합성 피처를 사용하며 네트워크 공격이나 실제 보안 침해를 발생시키지 않습니다. 실시간 Collector 그래프는 모의 데이터를 제외합니다. 모의 기록은 DB/API/화면에서 명확하게 구별되고 Slack을 호출하지 않습니다.

## 정답 복원과 매칭

5-tuple마다 PCAP의 패킷 시각과 방향을 모읍니다. CSV에 기록된 분 안에서 시작하며 전방/후방 패킷 수, 첫 패킷 방향, 지속시간(±2µs)이 모두 맞는 연속 패킷 구간이 **하나일 때만** 시각을 복원합니다. 레이블 값은 후보 선택에 사용하지 않습니다. 후보가 없거나 여럿이면 기존 60초 불확실성을 유지합니다. 이 불확실 구간과 다른 정답이 겹치면 충돌로 제외합니다.

|---|---:|---:|

| 빈 행 / 잘못된 지속시간 제외 | 288,602 / 15 | 0 / 47 |
| 패킷 증거로 시각 복원한 CSV 흐름 | 446,348 | 687,658 |

전체 5,957,427개 피처 중 4,891,978개가 매칭됐습니다. CSV의 흐름 수와 재생된 피처 윈도우 수는 다른 단위입니다. 금요일에는 BENIGN·DDoS·PortScan·Bot, 목요일에는 BENIGN·Infiltration·Brute Force·XSS·SQL Injection이 포함됐습니다. 모든 유형이 시간순 평가 구간에 포함되는 것은 아닙니다.

근거: [`alignment/`](../ml/reports/alignment/), [`labels/`](../ml/reports/labels/). 각 보고서는 원본 캡처·CSV·피처·결과 해시를 포함합니다. API는 캡처 해시와 피처 행 수가 일치하는 보고서만 제공합니다. 미확정 정답을 BENIGN으로 대체하지 않습니다.

## 동일 표본 모델 비교

정상 학습 3,384,391행, 시간순 평가 1,464,136행, 경계/장기 플로우 제외 4,064행. 시간 70% 지점 양쪽 10초를 비우고 경계를 가로지르는 플로우를 제외했습니다. 정상 학습 행에만 스케일러·모델을 적합했습니다. 두 모델은 IF 100 trees, contamination 0.05, random_state 42, decision_function < 0의 동일한 설정을 사용합니다. 테스트 결과에 맞춰 임계값을 조정하지 않았습니다.

| 지표 | 6개 피처 | 9개 피처 |
|---|---:|---:|
| Precision | 90.13% | 92.13% |
| Recall | 34.73% | 47.78% |
| F1 | 50.14% | 62.92% |
| FPR | 3.83% | 4.11% |
| TN / FP | 701,389 / 27,953 | 699,339 / 30,003 |
| FN / TP | 479,594 / 255,200 | 383,716 / 351,078 |

추가 피처는 이미 Collector가 계산하는 `source_pkt_rate`, `source_syn_rate`, `port_cnt`입니다. 다수의 짧은 연결로 나뉘는 공격에서 개별 플로우 수치만 사용하는 한계를 보완합니다.

9개 피처 실험의 DDoS 탐지율은 **38.58%** (160,596/416,239), PortScan 탐지율은 **59.80%** (190,482/318,555)입니다. 정상 729,342행 중 30,003행을 오탐했습니다. 따라서 **F1 목표 80% 미달, 운영 승인 false**이며 운영은 규칙 기반을 유지합니다. 미매칭·충돌 표본과 평가 구간에 없는 공격 유형에 일반화할 수 없습니다. 9개 피처 모델은 실험 디렉터리에만 보관하며 기존 6개 피처 운영 계약을 변경하지 않았습니다.

기존 F1 2.82%는 표본 161,667행(공격 2,356행)의 분 단위 정답 결합 결과였습니다. 새 모델과 표본 구성이 달라 직접적인 개선 폭으로 해석하지 않습니다. 원래 보고서는 [`baseline-minute.json`](../ml/reports/evaluation/baseline-minute.json)에 보존했고, 동일 표본 비교는 [`combined.json`](../ml/reports/evaluation/combined.json)에 기록했습니다.
